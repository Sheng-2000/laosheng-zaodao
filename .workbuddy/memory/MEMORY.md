## 日报生成铁律
- 唯一合法起点 = `template.html`（v2.17 铁律）：每次生成**必须**从模板空骨架出发、全量联网重生成，**严禁** `cp` 上一期成品报告再改数字。
- 数据源优先级：neodata-financial-search > westock-data > WebSearch；严禁编造数据。
- 涨红跌绿（A股惯例）：上涨/利好/正面 → 红 `#f85149`(`up`)；下跌/利空/负面 → 绿 `#3fb950`(`down`)；中性灰；数据蓝 `#00d4ff`；预警黄 `#f0b429`。高亮**不得改变字号**。

## 社区热门话题（2026-08-26 由10个精简为5个）
- 数量：**固定 5 个**（原 10 个，用户要求收敛）。模板/规范/质检三处已同步：
  - `template.html`：仅保留 `{{社区话题1~5_*}}` 占位符块，已删除 6~10。
  - `报告生成规范.md`：`{{话题1_内容}}`等（5个）。
  - `报告质量检查.md`：社区热门话题（5区域）全覆盖。

## 老盛观点去重（生成脚本必守）
- 模板已用 `<span class="lv-label">老盛观点：</span>` 渲染前缀。
- 因此填充 `{{社区话题N_观点}}` 的值**不得再带"老盛观点："前缀**，否则页面会双重显示"老盛观点：老盛观点："。
- 校验项：报告内 `老盛观点：</span>老盛观点：` 残留必须为 0。

## 页面布局（全屏适配，2026-08-26）
- 内容容器 `.inner` / `.header-inner` / `.tab-nav-wrap` 宽度上限 `max-width: 1680px`（原 1200px 在宽屏两边留白过大，用户要求放宽）；左右内边距 44px。
- 超宽屏断点：`@media (min-width:1900px)` → 放宽至 1860px(padding56)；`(min-width:2400px)` → 2200px(padding64)。
- 网格卡片最小宽度：highlight-grid 340px、market-grid 310px（全屏后卡片不过窄）。
- 调布局时只动容器 max-width / padding / 网格 minmax，**不得**触碰红涨绿、涨跌色语义、高亮字号、占位符结构。

## 质控要点（QC 脚本 /tmp/qc_*.py 已沉淀）
- 占位符 `{{` 剩余 = 0；`暂无数据` = 0；破折号（正文） = 0。
- 涨跌 class↔符号 矛盾 = 0（注意排除无符号百分比如"跌超10%"）。
- div/span 开闭平衡；不得有 `<style="...<span..."` 误嵌。
- 四大区域（机构/高股息/社区/操作）字数 ≥120；新闻/AI 卡高亮密度 ≥5，其余卡 ≥2。
- 数据时效性：交易日取 T-1 收盘；务必核对"财经早餐"类摘要是否误用 T-2 数据（曾混淆 8/24↔8/25）。
- 个股/上海金等具体合约数值须引交易所/权威个股页，不可依赖二手早餐摘要。
