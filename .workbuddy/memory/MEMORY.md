## 1. 生成铁律
- 唯一起点 = `规则/template.html`（v2.17 空骨架），每期**全量联网重生成**；严禁 `cp` 上期成品改数字（8/18 曾照抄 81%）。
- 数据源优先级：neodata-financial-search > westock-data > WebSearch；**禁编造数据**。
- 定时任务 agent 五步：搜 → 重写 g_data1/g_data2 → build → 高亮 → 质检 → 推送。`build.py` 只是渲染器，**严禁跳过重写直接 build 旧 g_data**。

## 2. 配色 / 字号
- 涨·利好 → 红 `#f85149`（`up`）；跌·利空 → 绿 `#3fb950`（`down`）；中性灰；数据青 `#00d4ff`；预警黄 `#f0b429`；动作橙 `#ffa657`。

## 4. 生成器工程
- 占位符 794 处 / 779 唯一，键名须带 `{{}}` 再 `re.sub`。中文引号：正文 “”，Python 定界 ASCII `"`。
- 架构：`g_data1.py`(市场/指数/情绪/速查/估值/综评) + `g_data2.py`(叙事/新闻/机构/社区/标的/高股息) → `build.py` 合并 → `hl_boost.apply(D)`（**必须合并后调用**）→ 填充 → `老盛早知道_YYYYMMDD.html`。
- 运行：`LAOSHENG_STATIC=1 <akshare venv python3> -u 脚本/build.py`；`-u` 必加（管道下块缓冲易误判挂死）。

## 5. 高亮（hl_boost.py）
- 优先级：带符号百分比 → 涨跌+数值 → 涨跌语义词 → 数字单位 → 主题词 → 实体词 → 机构产品名 → 产业技术词(青) → 动作词(橙)。已有颜色 span 用 `\x00N\x00` 保护，达标即 break。
- 词表分层 `_UPW/_DNW/_YEW/_ENT/_ORG/_TEC/_ORW`；缺词优先补 `_TEC`/`_ORG`。
- 密度：新闻/AI 卡 ≥5，其余卡 ≥2；数据展示卡（深度解读/关键数字速查/股息率对比/指数速览）豁免。

## 6. 质检四脚本（均 PASS 才通过）
- `qc_check.py` 数据及时性/结构样式/涨跌 class↔符号/高亮字号/switchTab/四区≥120字/社区格式/8市场块日期。
- `deep_qc.py` 语义色强矛盾、逐卡高亮密度、Tab5 十六卡同名同码、页头速览、8市场块着色。
- `cover_qc.py` Tab0-7 逐 Tab 高亮密度、标签语义、数据标注日期。
- `title_body_qc.py` 标题⇄正文主题一致性；n-gram 覆盖率 <0.08 判疑似错位；**只抓硬错位**，提炼式标题不算；跳过短分区标题与 `SKIP_WORDS` 章节名。
- **基线判定**：Tailwind 正则会命中自有类名 `grid-2/3/4`；「高亮 span 含 font-size」会命中模板自带 15px span → 均与 `规则/template.html` 对比计数，模板也有的记为继承项。
- **结论铁律**：初始 FAIL 先甄别「报告真缺陷」vs「脚本误报」，禁一见 FAIL 就改报告。
- **跨期守卫**：脚本期望值取自当期 g_data，只可信检查当期报告；检查往期只认结构性断言（数据层主数据日不在 [报告日-1, 报告日-5] 会输出 ⚠️ 跨期警告）。
- **关键数值/数据日一律动态取，禁硬编码上期值**。注意变量名：`cover_qc.py` 数据层叫 `_m`，`deep_qc.py`/`qc_check.py` 叫 `d1`/`d2`。
- 已知坑：①语义色正则误判「美债收益率上行→绿」需豁免；字面含利空词但整体利好（`相对受益`/`美元指数回落`/`美元走弱`）→ `EXEMPT_POS`；①-b **冲高回落**（盘中涨超但收跌→染绿正确）→ `EXEMPT_GREEN_REV`/`CTX_EXEMPT`：翻绿/收跌/转跌/跳水/回吐/回调/重挫/盘中一度涨/盘中涨超/前一日大涨；成本抬升→`EXEMPT_GREEN_COST`；利好出尽（提前透支/落地即兑现）→`CTX_EXEMPT`；②查 `class="hm-mq"` 而非 `hm-mq`；③切卡对 `finditer('<div class="card-body')` 起点切片，勿用 `re.split`；④Tab0/3/5 无 `card-body`，按组件/真实标题定位；⑤`importlib.util as _iu`；⑥真实失败用 `grep "  FAIL "`；⑦**四套 QC 默认 TARGET 已动态取当日**，`python 脚本/qc_check.py` 不带参即查当日报告，若 FileNotFoundError 说明被改回硬编码；⑧**补丁赋值行尾逗号会造 tuple**（`D["k"] = v,` → 1 元组，build 报 `can only concatenate tuple`），修复 `^D\[[^\]]+\]\s*=.*,$` 去尾逗号，写完补丁先跑「非字符串值检查」再 build。
- **语义色豁免已扩展（20260912）**：deep_qc `EXEMPT_POS` 增转折式利好（反而利多/削弱通胀预期/逆势收红/唯一收涨/而领跌/收红的/看领跌的是谁）+ 新增 `EXEMPT_GREEN_WARN`（风险：/警示：/需要冷静/别把…当利好/更适合作为观察/只能按年/而非配置）；cover_qc `CTX_EXEMPT` 同步。语义色告警先按这两张表甄别，绝大多数是误报，不要改报告。
- **n-gram <0.08 未必真错位**：提炼式标题本就不逐字入正文。先人工读卡确认同源，再决定是改标题（更贴合正文信息点）还是改正文。

## 6.5 独立体检方法论
- **四套脚本绿灯 ≠ 没问题**（20260909 全 PASS 仍查出 4 处数据缺陷）。加一轮独立核查四维：①各 Tab 中文字数/卡片数/高亮数；②全报告日期分布（主数据日应占绝对多数，未来日期须是日历事件）；③与上期逐句重复（区分模板静态/配置框架/政策原文/数据事实=合理继承 vs 观点结论句/核心叙事句=真照抄）；④关键数据回源。
- **逻辑自洽检查**（命中率最高）：收盘 14728 却写"盘中最高14635"→必错。同类：涨幅方向、涨跌幅与收盘/前收、占比之和、PB×股价与每股净资产。
- **跨源冲突**：优先新华社·新华财经，写明口径（日盘收/夜盘/盘中最高），不混用。
- **时点标注**："最新价"必须标明 T-1 收盘还是发稿时点。
- **内部一致性**：同一事实多处出现时日期/数值必须统一，用 grep 计数核对。
- **新闻覆盖兜底检索（20260910 教训，必做）**：四套 QC 只查结构与语义，查不出"漏新闻"。Tab1/Tab2 定稿前必须额外跑两次搜索兜底——「9月X日 财经要闻/重磅新闻」+「当日盘后 政策/公司 大事」，再逐条 grep 关键词计数确认已覆盖。曾漏掉当日最高权重事件（DeepSeek 筹备科创板 IPO）与两条部委级新闻。
- **旧闻必须标日期**：凡是 T-3 之前的消息（如 9/7 发布的模型、9 月初的财报），正文里必须写明发生日期，否则读者误判为 T-1 新闻。
- **涨跌家数口径**：平盘单独计。写"14涨2跌"而实际 13涨2跌1平属硬伤；银行股子集要另算（10 只银行股 8涨1平1跌），勿与 16 只标的口径混用。
