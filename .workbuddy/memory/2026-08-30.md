## 本次工程改进（可复用）

1. **生成器拆分为 3 个数据文件 + 渲染器**：`gen`（TAB0-1）、`gen2`（TAB2-4）、`gen3`（TAB4-7）+ `render`（渲染+后处理）。比单文件更好维护，也便于逐块调试。
2. **中文引号是最大的坑**：Python 数据文件里正文用 ASCII `"` 包中文短语会直接 SyntaxError。正确做法：正文一律用中文引号 “ ”，Python 定界符用 ASCII `"`。
   - 应急修复脚本：只对「前后都是 CJK/全角字符」的 `"` 做交替替换为 “ ”（这样不会误伤定界符）；**切忌**对裸词做全局 replace（会把 `S("保险","up")` 里的参数一起替换成中文引号）。
3. **booster 两个 bug**：
   - `if stack and all(stack)` → 空栈时整体为 False 导致**全文不高亮**，必须写 `if all(stack)`（空列表 all() 为 True）。
   - 只跟踪 `<span>` 不够：页眉/导航/标签类小字区域会被高亮。改为**跟踪所有容器标签**（带 VOID 集合排除自闭合标签），并加 `NO_HL_CLASSES`（hm-sub/hm-ticker/tab-btn/brand-*/stock-name/section-title/sub-title 等）直接判为不可高亮。
4. **QC 新增/修正的检查点**：
   - 情绪条宽度正则要写成 `style="width:([^;"]+)[;"]`（后面跟的是 `;` 不是 `"`）。
   - 统计正文 `--` 前必须**先剔除 `<!-- -->` 注释与 `<style>` 块**，否则 123 条注释会造成 246 处误报。
   - 问句检查要先 strip 标签再匹配（booster 会在标题里插 span）。
   - 「老盛观点」计数要用 `class="lv-label">老盛观点：`（注释和 CSS 里也有这个词，直接 count 会得到 12）。
5. **速查表涨跌 class 必须与符号一致**：本期 `速查1`（上证 -0.11%）误写成 `up`，被 QC「class="up" 无负值」抓出。该检查项很有价值，保留。
